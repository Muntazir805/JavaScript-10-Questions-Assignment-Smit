# JavaScript — 10 Practice Questions

A beginner-level JavaScript practice assignment completed as part of my **SMIT (Saylani Mass IT Training)** learning journey.

The purpose of this assignment is to strengthen my understanding of JavaScript fundamentals by solving 10 real-world programming problems using basic JavaScript concepts.

## About the Assignment

This assignment contains **10 JavaScript practice questions** covering:

* User input with `prompt()`
* Output using `document.write()`
* Variables
* Strings and numbers
* Arithmetic operators
* Comparison operators
* String concatenation
* `if...else` statements
* `if...else if...else`
* Arrays
* Array methods
* `for` loops
* `.length`
* Basic problem-solving and real-world logic

The solutions are intentionally written using beginner-level JavaScript without advanced concepts.

## Practice Questions

### 1. Online Shopping Checkout

Create a shopping checkout system that takes:

* Product name
* Product price
* Quantity

Then calculates and displays the total amount as a professional shopping bill.

### 2. Student Result System

Create a student result system that takes:

* Student name
* Total marks
* Obtained marks

Calculate the percentage and determine the student's grade and pass/fail status using conditional statements.

### 3. Bank Withdrawal System

Create a basic ATM withdrawal system.

The program takes:

* Account holder name
* Current balance
* Withdrawal amount

It checks whether sufficient balance is available and displays either the remaining balance or a transaction failure message.

### 4. Driving License Eligibility

Create a system that takes:

* Name
* Age

The program checks whether the user is **18 or older** and determines their driving license eligibility.

### 5. Hotel Room Booking

Create a hotel booking system that takes:

* Customer name
* Number of nights
* Price per night

Calculate and display the total hotel bill.

### 6. Employee Login System

Create a basic employee login system with a stored username and password.

The user enters their credentials using `prompt()`. The program checks whether both values are correct and displays the appropriate login status.

### 7. Delivery Charges System

Create a delivery charge calculator based on the order amount:

| Order Amount   | Delivery Charge |
| -------------- | --------------: |
| `$100` or more |            Free |
| `$50–$99`      |            `$5` |
| Below `$50`    |           `$10` |

The program calculates and displays the final amount.

### 8. School Attendance System

Create an array containing **10 student names**.

Use a `for` loop to display:

* Student serial number
* Student name
* Total number of students

### 9. Mobile Store Inventory

Create an array containing **5 mobile phone names**.

Practice the following operations:

1. Add a new mobile.
2. Remove one mobile.
3. Display all available mobiles using a `for` loop.
4. Display the total number of mobiles using `.length`.

### 10. Employee Salary Calculator

Create a salary calculator that takes:

* Employee name
* Basic salary

Calculate the bonus according to the employee's salary:

| Basic Salary     | Bonus |
| ---------------- | ----: |
| `$5,000` or more |   20% |
| `$3,000–$4,999`  |   10% |
| Below `$3,000`   |    5% |

Finally, calculate and display the employee's final salary.
